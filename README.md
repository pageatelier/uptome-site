# UPTOME static website starter

## 폴더 구성

- `index.html`: 홈
- `about.html`: 브랜드 소개
- `menu.html`: 메뉴
- `visit.html`: 위치 및 운영 안내
- `reservation.html`: 예약
- `en/index.html`: 영문 원페이지
- `assets/css/style.css`: 전 페이지 공통 디자인
- `assets/js/components.js`: 전 페이지 공통 헤더·푸터
- `assets/js/main.js`: 모바일 메뉴 등 공통 동작
- `assets/images/`: 실제 이미지

## 수정 순서

1. `assets/images`의 이미지를 실제 사진으로 교체합니다.
2. `index.html`의 홈 문구를 확정합니다.
3. 나머지 페이지의 임시 내용을 실제 내용으로 교체합니다.
4. `components.js`에서 인스타그램, 이메일, 메뉴 링크를 확정합니다.
5. GitHub 저장소에 이 폴더의 내용 전체를 업로드합니다.
6. Cloudflare Pages에서 정적 사이트로 배포합니다.

VS Code에서는 `index.html`을 Live Server로 열면 바로 확인할 수 있습니다.
