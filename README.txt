UPTOME 5-PAGE WEBSITE

구성
- index.html
- about.html
- menu.html
- visit.html
- reservation.html
- assets/css/style.css
- assets/js/components.js
- assets/js/main.js
- assets/images/*.svg

사용 방법
1. 폴더 전체를 GitHub 저장소에 업로드합니다.
2. Cloudflare Pages에서 저장소를 연결합니다.
3. assets/images 안의 SVG 임시 이미지를 실제 업투미 사진으로 교체합니다.
4. 이미지 파일명을 유지하면 CSS 수정 없이 바로 반영됩니다.
5. 메뉴 가격과 실제 코스명은 menu.html에서 수정합니다.

주의
- 홈 파일명은 반드시 index.html이어야 합니다.
- 공통 헤더와 푸터는 components.js에서 관리합니다.
- 모바일 메뉴와 스크롤 애니메이션은 main.js에서 관리합니다.
